---
title: Keyboard shortcuts
description: The keys that work everywhere, in the message box, in menus and in the artifact panel.
---

OCI can be used entirely from the keyboard. Every control is reachable with Tab and shows a visible focus ring, and a **Skip to main content** link is the first tab stop on every page. On Windows and Linux, read `Cmd` as `Ctrl`.

## Everywhere

| Keys | Does |
|---|---|
| `Cmd + K` | Search your conversations and run commands: new chat, history, models, attachments, settings, theme, sidebar, and admin pages for administrators and auditors. |
| `Cmd + Shift + O` | Starts a new conversation. |
| `Cmd + B` | Shows or hides the sidebar. |
| `Cmd + /` | Opens the model picker, with its search ready for typing. |
| `Escape` | Closes the open dialog, menu or panel and returns focus to whatever opened it. |

`Cmd + Shift + O`, `Cmd + B` and `Cmd + /` work anywhere in the chat (a new chat, a conversation or a project), though not in Settings or Admin, including while you are typing a message, but not while an input method is composing text. `Cmd + /` needs a message box with a model picker, so it does nothing on a project page. Search (`Cmd + K`) lists the same shortcuts beside **New chat** and the sidebar command, and the **Keyboard Shortcuts** card in Settings lists them all.

## In the message box

| Keys | Does | With **Invert Send/New Line Behavior** |
|---|---|---|
| `Enter` | Sends the message | Starts a new line |
| `Shift + Enter` | Starts a new line | Starts a new line |
| `Cmd + Enter` | Sends the message | Sends the message |

When you edit a message you already sent, `Enter` starts a new line and `Cmd + Enter` submits; `Escape` cancels the edit. Keys pressed while an input method (IME) is composing text are left alone.

## Lists, menus and tabs

| Keys | Does |
|---|---|
| `↑` `↓` | Move through command palette results, menus and the model picker. |
| `Home` `End` | Jump to the first or last result or tab. |
| `←` `→` | Move between tabs, such as on a project page or in admin pages. |
| `Enter` | Choose the highlighted item. |

## Artifacts

| Keys | Does |
|---|---|
| `Escape` | Leaves an edit, then full screen, then closes the panel. |
| `Cmd + Enter` | Saves an edited document as a new version. |
| `Tab` | After clicking inside a preview, moves out of it. |
| `←` `→` | On the panel's edge (**Resize artifact panel**), `←` makes the panel wider and `→` narrower; with `Shift`, in bigger steps. |
| `Home` `End` | On the panel's edge, make it as narrow or as wide as it goes. |
| `Enter` | On the panel's edge, return it to the usual width. |
